# Lesson 1 — чёрный фон, без бренда Koi (16:9, 67.3 с)

**v2 (13.11.2026):** исходник заменён на исправленную озвучку («approved payout»); картинка та же, маска переиспользована.
Надпись — просто «LESSON 1» без линий по бокам. Добавлены золотые субтитры.

Исходник: говорящая голова на фоне неоновой «K», кружка с «K», надпись LESSON 1 (белая), 68.7 с, 1918×1080.

## Что сделано
- **Фон удалён полностью.** Маска ведущего: Robust Video Matting (ResNet50, ONNX, `downsample_ratio=0.25`),
  `tools/lesson1_blackbg/matte.py`. Остаются человек и микрофон; неон «K», кружка с «K», полки, ноутбук и стол уходят.
- **Новый фон:** чёрный, очень слабое тёплое золотое свечение за ведущим.
- **Зелёный засвет на ведущем → золото:** избыток зелёного канала переносится в золотой оттенок (контровой свет стал золотым).
- **Надпись:** «LESSON 1» сверху справа, золотой металлический градиент, Inter Display SemiBold 34 px, разрядка;
  появляется за 0.6 с. Линии по бокам убраны по правке. Логотип не добавлялся.
- **Субтитры:** золотой градиент (как у надписи), Inter Display Bold 60 px, мягкая тёмная тень, по центру внизу (y≈1000 —
  ниже рук ведущего, на чёрном; в гайде ~900, опущено для читаемости). 1–2 смысловых слова на экран, экран не
  заканчивается служебным словом; fade-in 0.12 с. Тайминги — по словам из ASR (`words.json`).
- **Упоминание бренда в речи:** «Next, we learn what KoiPay provides and how the platform works» →
  вырезаны кадры 1946–1989 (64.87–66.33 с) → «Next, we learn how the platform works.» Склейка закрыта панч-ином ×1.08.
  Других упоминаний Koi в речи нет (проверено ASR: Parakeet TDT 0.6B v2, `words.json`).
- Исходник уходит в чёрное на кадре 2050 → плавный уход в чёрное за 0.5 с.
