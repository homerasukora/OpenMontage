# Security deposit — обучающее видео, Ganesha Pay Noir (16:9, 1:27, 30 fps)

Исходник: `Deposit.mp4` — запись экрана кабинета (1920×1080, приложение в центре ~1276×722) + голос автора. Не резали.

- **Логотип Surfgate** в шапке приложения (x 344–442, y 178–236) залит цветом шапки (#191919, шапка однотонная) —
  без следов; линия под шапкой не тронута.
- **QR-код и адрес кошелька оставлены как есть** — по указанию: обучающий пример для действующих трейдеров.
- Компоновка: приложение в рамке (1400×792, золотая обводка) на ониксе с изумрудным свечением, логотип Ganesha Pay
  слева сверху, справа колонка плашек под речь:
  Security deposit → Why a deposit? (Mutual guarantee, You hold our funds, Protects both sides, Your working capital,
  Your payment limit) → Bigger deposit (Accept more funds, Hold funds longer, Before settlement) →
  How to deposit (1 Deposit USDT, 2 Enter 2,000 USDT, 3 Network: TRC20, 4 Proceed, 5 Send USDT to QR).
- Камера по приложению: наезд на кнопку Deposit USDT (63 с), на окно суммы/сети (66–75 с), на окно с QR (76–82 с).
- Субтитры по словам, ключевые слова золотом. Правки распознавания (сверено Whisper): «our phones» → «our funds»,
  «That's a 24 example» → «TRC20, for example», «your code … why» → «your QR code … where», «what you/we» → «that».
- Звук: голос −18 LUFS постоянным усилением, highpass 80 Гц + лёгкий afftdn, подложка `bed.py` −25 дБ, итог ≈ −15 LUFS.
