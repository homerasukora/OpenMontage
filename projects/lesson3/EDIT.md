## Камера (render.py, по умолчанию; `--static` — без неё)
Работает на готовом композите (человек уже на фоне), маску не трогает.
- Планы: общий 1.00 / средний 1.12 / крупный 1.24; при зуме камера держит лицо (якорь — медиана положения головы
  по маске на отрезке, лицо на 36 % высоты кадра).

  отъезды — плавно. Внутри плана медленный наплыв +2.5 %. В начале — проявление из чёрного 0.3 с.
