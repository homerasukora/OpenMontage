# m_redactor_bot — форматирование постов Ganesha Pay

Telegram-бот на Cloudflare Workers. Владелец присылает черновик на английском, бот оформляет его в стиле канала
(жирный заголовок с эмодзи, жирный курсив для имён и бренда, цитата с пунктами, CTA с 👇, хештег, кнопки)
и показывает превью. Публикация **только** по кнопке «📤 Опубликовать» и **только** в канал из `CHANNEL_ID`.

## Как устроено
- Нейросеть: **Cloudflare Workers AI**, без внешних ключей. Основная модель `@cf/qwen/qwen3.8-27b`,
  при ошибке подключается `@cf/openai/gpt-oss-120b`. Бесплатно 10 000 neurons в день,
  один пост стоит около 80–200 neurons, этого хватает на 50+ постов в день.
- Модель возвращает только **структуру** поста в JSON (заголовок, абзацы, цитата, CTA, хештег, кнопки).
  HTML для Telegram собирает код (`src/render.js`), поэтому разметка всегда валидна и в стиле канала.
- Код сверяет результат с черновиком: числа (лишние или пропавшие), пропущенные и повторённые предложения,
  новые слова. Если что-то не так, модель получает одну попытку исправить. Что осталось — бот пишет в заметке 📝.
- Отдельно отмечаются рискованные формулировки: guaranteed, passive income, no risk, 100% safe,
  «без блокировок», easy money, обещания дохода.
- Если ИИ недоступен, бот делает простую раскладку без нейросети.
- Рупии автоматически приводятся к индийскому формату: ₹312075 → ₹3,12,075.
- Доступ: только `OWNER_ID`, остальным «Это закрытый бот.»
- Ссылки на кнопках: менеджер `smmtg-mng`, старт работы `smmtg-p2p`, Academy EN `smmtg-acen` и HI `smmtg-achi`.
  Подписи — короткие CAPS, как в канале (WRITE OUR MANAGER, START WORKING, ENGLISH COURSE…).
- Премиум-эмодзи, режим `PREMIUM_EMOJI="owner"` (сейчас): у владельца бота есть Telegram Premium, но у бота нет
  юзернейма с Fragment (привязка к боту стоит ~$1000). Telegram разрешает такому боту премиум-эмодзи только в личке.
  Превью приходит с премиум-эмодзи; «🙋 Опубликую сам» присылает чистую копию — её пересылают в канал
  со «Скрыть имя отправителя». Бот ловит `channel_post` (совпадение по тексту, ждёт 30 минут), добавляет кнопки
  (нужно право «Редактирование сообщений»), реакции и статус Posted. «📤 Бот» публикует сам, но с обычными эмодзи.
  Премиум-иконок на кнопках в этом режиме нет.
- Режим `PREMIUM_EMOJI="on"` (collectible username с Fragment, привязанный к боту):
  обычные эмодзи в тексте заменяются премиум-версиями — из постов канала (`premium_emoji.json`)
  и свои, присланные через /emoji (хранятся в KV `pe:map`). На кнопке-ссылке — премиум-иконка
  (авто по ссылке: 💬 менеджер, 🚀 старт, 👨‍🎓 курс; или своя через «😀 Эмодзи»), на реакциях — присланный премиум-эмодзи.
  Если Telegram отказывает, превью уходит с обычными эмодзи и заметкой; /channel показывает юзернеймы бота.

## Контент-план
Кнопка «📅 Контент-план» (или /plan) показывает даты из Google Sheets «Content Plan / Ganesha Pay (TG / FB / X)»
на 2 недели вперёд. Нажимаешь дату или пишешь её сообщением (`29.11`), и бот:
1. берёт TEXT и визуал из LINK TO VISUAL (файл Google Drive или картинка в ячейке);
2. оформляет текст: хештег и ссылки из текста сохраняются, ссылка `g.ganeshapay.io/...` становится кнопкой,
   а подпись кнопки (CAPS, как в канале) придумывает модель;
3. показывает превью с картинкой. Текст до 1024 символов идёт подписью к фото. Длиннее — картинка
   стоит крупным превью над текстом (`/img/<id>` воркера), видео — отдельным сообщением;
4. после публикации ставит STATUS = Posted в таблице (`PLAN_STATUS="off"` в `wrangler.toml` отключает).

Доступ к таблице даёт Google Apps Script `apps_script/Code.gs`: он работает от имени владельца таблицы
и отвечает только на запросы с ключом. Ключей Google в Cloudflare нет.

Настройка (один раз):
1. Таблица → Расширения → Apps Script → вставить `apps_script/Code.gs` → сохранить.
2. ⚙️ Настройки проекта → Свойства скрипта → добавить `BOT_KEY` = длинный случайный пароль.
3. Выбрать функцию `testList` → ▶ Выполнить → разрешить доступ → в журнале появится список постов.
4. Начать развёртывание → Новое развёртывание → тип «Веб-приложение»; Запуск от имени: «Я»;
   У кого есть доступ: «Все» → Развернуть → скопировать URL веб-приложения.
5. Cloudflare → Workers → m-redactor-bot → Settings → Variables and Secrets → два Secret:
   `PLAN_URL` = URL веб-приложения, `PLAN_KEY` = тот же пароль, что в `BOT_KEY`.
6. Открыть /setup воркера ещё раз, чтобы в меню бота появилась команда /plan.

После правок `Code.gs`: Развертывания → Управление → ✏️ → Версия: «Новая версия» (URL не меняется).

## Кнопки превью
- 📤 Опубликовать · 🔁 Другой вариант
- ✏️ Поправить текст — правка словами, можно по-русски (или reply на превью). Так же меняется хештег: «хештег #ask».
- 🖼 Добавить/Заменить визуал — бот ждёт фото или видео и прикрепляет его к посту (или просто ответь фото на превью).
  Если в плане визуала нет (в ячейке слово вроде «Дашборд»), бот сам пишет, что там указано, и ждёт фото.
- 🔘 Кнопки — редактор: кнопки поста показаны как есть, нажми на любую, чтобы настроить.
  - Кнопка-ссылка: ✏️ текст · 🔗 ссылка (менеджер / старт / курс EN / курс HI / своя) · цвет · 🗑.
  - Реакции: ряд кнопок-эмодзи со счётчиком (❤️ 12 | 🔥 5). Добавляются одним сообщением: «❤️🔥👍», можно премиум.
    У каждой — 😀 смена эмодзи · цвет · 🗑. Подписчик нажимает — +1; нажал ещё раз — снял; нажал другую — голос переходит.
    Счётчики хранит Durable Object `Reactions` (один на пост, SQLite), кнопки в канале обновляются не чаще раза в секунду.
    Премиум-эмодзи сохраняется (`icon_custom_emoji_id`) и показывается на кнопке, когда `PREMIUM_EMOJI="on"` (нужен username с Fragment).
  - Цвет: ⚪ обычный → 🟢 зелёный → 🔵 синий → 🔴 красный (поле `style` Bot API).
  Кнопки, изменённые вручную, сохраняются при «Поправить» и «Другой вариант».

После публикации: «Открыть пост», «🗑 Удалить из канала».

## Деплой
```bash
npm install
npx wrangler login
npx wrangler deploy
```
Секреты `BOT_TOKEN`, `PLAN_URL`, `PLAN_KEY` задаются в Cloudflare Dashboard → Workers → m-redactor-bot → Settings → Variables and Secrets
(тип **Secret**). В чат его не присылать.
Затем открыть https://m-redactor-bot.m-redactor-bot.workers.dev/setup: ставит webhook с секретом и команды бота.

Сменить модель: `MODEL` в `wrangler.toml`.

## Проверка без сети
```bash
npx wrangler deploy --dry-run --outdir dist
node test/sim.mjs $PWD/dist/index.js           # моки Telegram и Workers AI
AI_FAIL=1 node test/sim.mjs $PWD/dist/index.js # ИИ недоступен -> раскладка без нейросети
node test/plan_sim.mjs $PWD/dist/index.js       # контент-план: даты, пост с картинкой, публикация, статус
node test/plan_sim.mjs $PWD/dist/index.js long  # длинный текст -> картинка крупным превью
node test/edit_sim.mjs $PWD/dist/index.js       # нет визуала -> фото; редактор кнопок; реакции и счётчики
node test/premium_sim.mjs $PWD/dist/index.js    # режим on: премиум в тексте и на кнопках, /emoji, запасной вариант
node test/owner_sim.mjs $PWD/dist/index.js      # режим owner: копия для пересылки, кнопки на пересланный пост
```

## Настройка промпта на живой модели
`POST /debug` работает, только пока задан секрет `TEST_KEY` (заголовок `X-Test-Key`).
Тело запроса: `{draft, model?, layout?, instruction?, variant?}`. После настройки секрет удалить:
`npx wrangler secret delete TEST_KEY`.
