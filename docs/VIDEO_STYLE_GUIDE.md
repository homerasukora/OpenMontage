# KoiPay — визуальный стиль видео (референс)

Разбор эталонного ролика (talking head, 1920×1080, 30 fps, ~71 с, тема: PayIn / PayOut / dashboard / Koi Academy / KoiPay Bot) и 4 статичных постеров. Кадры-референсы лежат в `docs/style_refs/`.

> Значения ниже **сняты с референса**, а не из официального ТЗ. По правилу из `CLAUDE.md` (раздел 10) актуальное ТЗ на субтитры имеет приоритет. Если ТЗ появится и разойдётся с этим файлом — используем ТЗ.

## 2. Субтитры (talking head)

- **Позиция:** по центру по горизонтали, внизу, базовая линия ~y = 900 из 1080 (≈83% высоты).
- **Объём:** 1–2 слова на экран, смена синхронно с речью (по словам/фразам, не по предложениям).
- **Шрифт:** геометрический гротеск, SemiBold/Bold (визуально близко к Gilroy / Outfit — **точный шрифт уточнить**). Размер ~56–60 px при 1080p.
- **Цвет:** белый; **ключевые термины — неоновый зелёный** целиком (UPI, banking, payment request, PSP, KoiPay, PayIn, incoming payment, outgoing payment, dashboard, commission, P2P, Koi Academy, second link, KoiPay Bot, onboarding). Служебные слова рядом остаются белыми («or **PSP**», «**banking** in», «the **dashboard**»).
- **Обводка/тень:** без плашки, мягкая тёмная тень для читаемости.
- **Анимация появления:** быстрый fade-in с лёгким blur ~0.1–0.15 с; исчезновение такое же или жёсткая смена.

## 3. Инфографические плашки

- **Позиция:** правый верхний угол, примерно x 1170–1850, y 110–650 (≈680×540 px при 1080p). Ведущий остаётся слева/по центру, плашка не перекрывает лицо.
- **Форма:** тёмная полупрозрачная «стеклянная» карточка, скругление ~30 px, тонкая неоновая обводка 2 px с лёгким свечением.
- **Внутри:** водяной знак — контур K-логотипа очень низкой яркости; линейные иконки в неоне (человек, магазин, банк, телефон UPI, чип PSP, колокольчик, шапка выпускника, Telegram-самолётик, иконки Activity/History/%); подписи белым мелким жирным шрифтом.
- **Пилюли (бейджи):** скруглённые капсулы с неоновой обводкой или зелёной заливкой — «Payment Service Provider», «P2P processing platform», «Approved requests», «Confirmed in dashboard», «step by step», «Links in description», `@koipaybot`, `@koiacademybot`. Тег-лейбл в углу карточки («PayIn», «PayOut»).
- **Анимация (build-up):** элементы появляются последовательно под речь — иконка fade-in → стрелка «прорисовывается» слева направо (~0.3–0.5 с) → второй объект → пилюль снизу. Активный шаг подсвечивается заливкой (степпер Receive → Process → Confirm; список Activity/History/Commission заполняется зелёным по очереди).
- **Смена тем:** плашка исчезает, 1–3 с «чистый» кадр с неоновым K за ведущим, затем новая плашка. Переход логотипа: неоновый K может «вспыхнуть» поверх плашки при упоминании KoiPay.
- **Когда ставить:** только там, где плашка объясняет механику. Приветствие, переходы, риторические вопросы («experienced?») — без графики.

## 4. Структура ролика

1. Хук / контекст (UPI, онлайн-банкинг в Индии).
2. Базовая механика: Customer → Business → PSP.
3. Что такое KoiPay (P2P processing platform, approved requests, registered traders).
4. PayIn → PayOut → шаги работы → dashboard (activity, history, commission).
5. Для новичков: Koi Academy («First link in description»).
6. Для опытных: KoiPay Bot, `@koipaybot` / `@koiacademybot` («Links in description»). Один CTA-блок в конце.

## 5. Съёмка (если снимаем сами)

Тёмный офис, неоновая вывеска K на стене за ведущим справа, зелёная подсветка стола / контровой свет, ведущий в чёрном, микрофон на стойке в кадре. Кадр статичный, средний план.

## 6. Статичные постеры / обложки

- Чёрный фон, тонкие вертикальные светящиеся линии с точками на концах, перспективная сетка пола.
- Логотип K в стеклянном квадрате + «Koi Pay» белым — левый верхний угол.
- Заголовок 2 строки: одна строка белая, вторая неоновая (или порядок наоборот), очень жирный гротеск; тонкая вертикальная зелёная линия слева от заголовка.
- Человек с зелёной контровой подсветкой справа; 3D-объекты в стеклянно-неоновом стиле (иконка Instagram, кубок с K, карта Индии с кольцами).
- CTA снизу: подчёркнутый текст со стрелкой («Deepak's story →») или стеклянная пилюля («Drop them in DM»).
